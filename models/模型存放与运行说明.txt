================================================================================
ExamSplit AI - 本地轻量模型存放与运行说明指引
================================================================================

本 models 目录专为 ExamSplit AI 的“本地离线轻量模型切题流水线”设计。
您可以根据自身设备与网络环境，选择以下三种使用方式之一：

--------------------------------------------------------------------------------
【方式一：极速规则模式（0 门槛，无需下载任何模型，最推荐日常使用）】
--------------------------------------------------------------------------------
ExamSplit AI 内置了工业级高精几何与版面拓扑解析引擎（基于 PyMuPDF + 拓扑阅读流）。
在软件顶部菜单【更多功能 ▾】->【🧪 本地模型切题实验...】中：
- 将运行模式切换为：“极速规则模式 (仅本地规则，0秒VLM延迟)”
- 无需下载任何大模型，无需启动任何后台服务，0 内存/显存占用，毫秒级快速切题！
- 实测对于 90% 以上标准排版试卷（如考研数学一二三、高考数学物理等），均可实现 100% 准确提取！

--------------------------------------------------------------------------------
【方式二：Ollama 一键托管运行（推荐本地拥有 GPU 显卡的用户）】
--------------------------------------------------------------------------------
1. 访问 https://ollama.com 下载并安装 Ollama；
2. 打开系统终端或 PowerShell，执行以下命令拉取并启动模型：
   ollama run qwen2.5vl:3b
3. 启动 ExamSplit AI，打开【🧪 本地模型切题实验...】：
   - 服务端点保持默认：http://127.0.0.1:11434/v1
   - 模型名称保持默认：qwen2.5vl:3b
   - 点击【测试连接】，显示“连接正常”即表示配置成功！
   - 点击【🚀 开始本地切题分析】即可享受“本地规则秒切 + 本地小 VLM 智能疑难复核”的双重保障！

--------------------------------------------------------------------------------
【方式三：放入本 models/ 目录并通过 llama-server 启动】
--------------------------------------------------------------------------------
1. 下载 GGUF 格式的视觉大模型：
   - 推荐模型：Qwen2.5-VL-3B-Instruct (量化版本 Q4_K_M，体积约 3.0GB)
   - 可在 HuggingFace 或 ModelScope 魔搭社区搜索并下载：
     Qwen2.5-VL-3B-Instruct-Q4_K_M.gguf
2. 将下载好的 .gguf 文件直接放入当前 models/ 文件夹中；
3. 使用 llama.cpp 编译自带的 llama-server 启动（支持 Windows / Linux / macOS）：
   Windows 示例：
   llama-server.exe -m models\Qwen2.5-VL-3B-Instruct-Q4_K_M.gguf --port 11434 -ngl 99 -c 4096
   Linux 示例：
   ./llama-server -m models/Qwen2.5-VL-3B-Instruct-Q4_K_M.gguf --port 11434 -ngl 99 -c 4096
4. 启动后，ExamSplit AI 即可通过 http://127.0.0.1:11434/v1 自动对接！

--------------------------------------------------------------------------------
【常见问题与技术支持】
--------------------------------------------------------------------------------
Q: 为什么我的笔记本电脑运行大模型很卡？
A: 建议直接使用【方式一：极速规则模式】。对于试卷切题，版面拓扑规则已经足够强大，完全不消耗任何显存与 CPU 资源。
Q: 遇到题目切分边界不理想怎么办？
A: 可以在实验仪表盘中点击【应用实验结果到工作区】，随后在主界面右键拖拽或点击选框微调手柄进行微米级手动调整，原卷矢量保真。
